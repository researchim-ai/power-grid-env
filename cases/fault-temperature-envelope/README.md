# Холодный/горячий кабель: непрерывный диапазон токов КЗ

Это отдельный достаточный инженерный экран DES-04, не замена динамической
проверке пуска и селективности. Используются исходные паспорта из
`cases/equipment-catalog`, а не новые синтетические значения оборудования.

Два профиля: `envelope.json` — металлическое трёхфазное КЗ;
`resistive.json` — сопротивление КЗ 0..0,01 Ом на фазу. Температура меди
20..90°C, напряжение источника 0,95..1,05 номинального, точка КЗ 0..100%
длины кабеля. Это явные допущения владельца, не нормативные коэффициенты.
Настройки VI и допуски перенесены из существующего профиля защит.

Из корня репозитория:

```bash
python -m power_grid_env.fault_temperature_envelope \
  --catalog cases/equipment-catalog/catalog.json \
  --brief cases/equipment-catalog/brief.json \
  --selection cases/equipment-catalog/selection-250.json \
  --envelope cases/fault-temperature-envelope/resistive.json \
  --out reports/my-cold-hot
```

Выходной каталог должен отсутствовать. Код выхода 2 означает, что достаточные
условия не выполнены; пакет с результатом всё равно сохраняется. Не трактуйте
это автоматически как доказательство непригодности реальной установки.
`verify_envelope(root, expected_inputs=...)` требует все четыре исходных
объекта владельца, пересчитывает результат и проверяет неизменность пакета.
Переподписание подменённого результата не заменяет пересчёт.

Независимая алгебраическая проверка:

```bash
python -m benchmarks.fault_temperature_reference \
  --catalog cases/equipment-catalog/catalog.json \
  --brief cases/equipment-catalog/brief.json \
  --selection cases/equipment-catalog/selection-250.json \
  --envelope cases/fault-temperature-envelope/resistive.json \
  --out reports/my-cold-hot-reference
```

Эталон собирает двухузловую комплексную матрицу с конечным шунтом КЗ
непосредственно из исходных паспортов. Болт и нулевая длина проверяются
точными предельными выражениями. Независимая временная траектория не решается.

## Почему границы непрерывны

Для положительных Rт, неотрицательных Xт, Rкаб, Xкаб, Rкз и положительного
температурного коэффициента:

`I = c U / (sqrt(3) |Rт + p Rкаб(T) + Rкз + j (Xт + p Xкаб)|)`.

Ток возрастает с c и убывает с T, p и Rкз. Поэтому экстремумы тока лежат
на углах непрерывного прямоугольника параметров. При p=0 температура не
влияет на ток. Паспортный предел рабочей температуры не превышается;
250°C конца короткого замыкания не считается начальной рабочей температурой.

Времена trip убывают по току и возрастают по pickup и TMS. Нижняя граница
backup trip минус верхняя primary clear даёт достаточный запас селективности,
даже если эти два времени достигаются при разных токах. Для I²t используется
`Imax² * tclear,max`: это верхняя оценка, а не заявленный точный максимум.
Несрабатывание отображается JSON null и отрицательной проверкой чувствительности.
Момент открытия выключателя входит в I²t и clear, но не в trip.

Проверяются оба аппарата, кабель, трансформатор и бюджет времени владельца.
Токи считаются постоянными до отключения; все выдержки ограничиваются областью
применимости переданных кратковременных и адиабатических характеристик.

## Ограничения

Нет подпитки двигателя/генератора, нагрузочного тока, апериодической составляющей,
несимметрии, взаимодействия защит во времени, нагрева во время КЗ и обратной
связи температуры с динамической сетью. Rт выведено из паспортных потерь при
паспортной температуре и здесь фиксировано: материал обмотки не выдумывается.
Исходные k кабеля и выдержка трансформатора остаются допущениями каталога;
аутентичность производителя и нормативная пригодность не подтверждаются.
Никаких наград для обучения этот экран не выдаёт.
