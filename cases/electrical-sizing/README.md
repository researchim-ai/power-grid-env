# DES-02: предварительный электрический расчёт

Симметричный радиальный фидер до 1 кВ, один трансформатор, одна линия,
отстающая нагрузка постоянного паспортного kVA. Каталог демонстрационный:
значения не являются паспортами производителя или нормативными таблицами.
Все поправки задаёт владелец вместе с происхождением и условиями применимости.
Температура фиксируется для прослеживаемости; сопротивление уже должно быть
приведено к рабочей температуре, коэффициенты автоматически не выводятся.

```sh
python -m power_grid_env.cli electrical-sizing --input cases/electrical-sizing/task.json --proposal cases/electrical-sizing/accepted.json --out /tmp/sizing-accepted
python -m power_grid_env.cli verify-electrical-sizing /tmp/sizing-accepted --input cases/electrical-sizing/task.json --proposal cases/electrical-sizing/accepted.json
```

`rejected.json` демонстрирует недопустимый кабель. Код выхода 2 означает отказ
по критериям или ошибку; JSON различает результаты. Верификация пересчитывает
все величины, включая отрицательный результат. Manifest обеспечивает целостность,
а переданные отдельно task/proposal — привязку к исходным требованиям.

Расчёт проверяет напряжение изоляции, допустимый ток после трёх поправок,
линейное падение напряжения только в кабеле, загрузку трансформатора,
I²t кабеля, отключающую способность и паспортный ток/длительность стойкости
трансформатора. Для кабеля используется худшее КЗ у начала линии; использование
только тока в конце линии могло бы занизить термическую нагрузку. Время отключения
задано владельцем, а не вычислено из характеристики защиты. Стойкость
трансформатора проверяется непосредственно по паспортным току и времени,
без экстраполяции по I²t.

Уравнения и границы сверены с Schneider Electric Electrical Installation Guide:

- [Поправки допустимого тока](https://www.electrical-installation.org/enwiki/General_method_for_cable_sizing).
- [Падение напряжения](https://www.electrical-installation.org/enwiki/Calculation_of_voltage_drop_in_steady_load_conditions): √3 I L (R cosφ + X sinφ).
- [КЗ трансформатора](https://www.electrical-installation.org/enwiki/Short-circuit_current_at_the_secondary_terminals_of_a_MV/LV_distribution_transformer): пример 400 кВА, 420 В, 4% даёт около 13.7 кА.
- [Адиабатическая стойкость](https://www.electrical-installation.org/enwiki/Verification_of_the_withstand_capabilities_of_cables_under_short-circuit_conditions): I²t ≤ k²S²; профиль ограничен временем до 5 с.

Проверки включают независимое комплексное решение фазного эквивалента,
опубликованный пример трансформатора, пределы, отказы и подмену артефактов.
Это не независимый промышленный симулятор и не нормативное одобрение.
Не учтены вклад двигателей в КЗ, ударный ток, земляные КЗ, нейтраль, гармоники,
селективность, реальная нелинейная нагрузка и изменение температуры.
Результат пока не соединён с динамическим вердиктом DES-01: прохождение
статических проверок не означает успешный пуск. DES-02 остаётся in_progress
до реального каталога и сквозной проверки выбранного оборудования.
