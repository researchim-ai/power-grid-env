# Deterministic sensor-noise examples

Frozen independent B15 motulator observations, re-used with explicitly authored
noise (not equipment measurements). Generated by
`benchmarks.noisy_identification_acceptance.specimen`, seed 17001.

- `linear-noise.json`: raw training-speed fit, expected accepted audit.
- `linear-speed-filter.json`: explicit training-only quadratic speed smoothing,
  window 9, expected accepted audit against the same **raw** observations.
- `heldout-current-bias.json`: +0.004 A on held-out iα, expected rejection by
  mean residual despite passing the old peak-error rule.

Run `python -m power_grid_env.cli audit-dynamic-motor --input FILE --out NEW_DIR`.
See `docs/NOISY_IDENTIFICATION_RU.md` for limits, provenance and acceptance.
