# DES-02: оборудование и динамика в одном исследовании

Профиль объединяет статические проверки [electrical-sizing](../electrical-sizing/README.md)
и трёхсеточные исследования [DES-01](../design-curriculum/README.md).
В каталоге — синтетические кабели 95/16 мм² и трансформатор 250 кВА.
Двигатель — синтетический single-cage 75 кВА / 400 В с вентиляторной нагрузкой.
Это демонстрация воспроизводимого процесса, а не комплект паспортов производителя.

```sh
python -m power_grid_env.cli equipment-design --input cases/equipment-design/task.json --proposal cases/equipment-design/accepted.json --out /tmp/equipment-accepted
python -m power_grid_env.cli verify-equipment-design /tmp/equipment-accepted --input cases/equipment-design/task.json --proposal cases/equipment-design/accepted.json
python -m benchmarks.equipment_sizing_reference --input cases/electrical-sizing/task.json --proposal cases/electrical-sizing/accepted.json --out /tmp/equipment-reference
```

`rejected.json` выбирает недостаточный кабель. CLI возвращает 0 только при
прохождении всех объявленных требований; отказ/ошибка — 2. Статический отказ
не отменяет динамические испытания. Неполный или численно неквалифицированный
результат получает reward=null, а не пригодную для обучения метку отказа.
Верификатор перепроверяет оба вложенных пакета, точную компиляцию выбранного
оборудования и итоговый вердикт. Чтобы обнаружить изменение самого задания,
при проверке передавайте доверенные `--input` и `--proposal`.

## Как оборудование входит в физику

Кабель задаёт полное последовательное R+jX из рабочего сопротивления и длины;
его rating_a равен допустимому току после поправок. Трансформатор задаёт
эквивалент Тевенина на стороне НН: Zbase=U²/S, R=Zbase·ur/100,
X=Zbase·sqrt(uk²−ur²)/100. Первичная сеть предполагается жёсткой, ветвь
намагничивания отсутствует. Подмена исходного источника этим эквивалентом —
явная политика компилятора; прежний импеданс источника не прибавляется.
Номинальное напряжение источника — напряжение холостого хода.

Поддержаны ровно два узла, один источник и одна линия, все двигатели и
пассивные отстающие вспомогательные нагрузки расположены за линией.
Запрещены дополнительные источники, перемычки, трансформаторы и шунты.
Мощность статического задания должна покрывать сумму номинальных VA двигателей
и модулей вспомогательных нагрузок; это консервативное условие связности
исходных данных, а не модель фактического длительного потребления.
Предельные критерии, события и механические нагрузки сохраняются.

На каждый вариант выполняются пуск, повторные провалы питания и
выбег/повторное включение — по три сетки с аудитами в изолированных процессах.
Итог accepted возможен только при прохождении статических и динамических
критериев. `normative_approval=false` всегда.

## Независимая проверка и ограничения

`benchmarks.equipment_sizing_reference` строит собственную схему OpenDSS
непосредственно из каталога и решает КЗ в обоих концах кабеля. Сохраняются
команды, токи всех фаз, версия движка и wrapper, fingerprint и manifest.
Допуск относительной ошибки 2e-6 зафиксирован до сравнения. База и частота
OpenDSS явно заданы 50 Гц. Объект КЗ имеет сопротивление 1e-8 Ом.
Использованы [официальные модели Vsource](https://opendss.epri.com/Vsource.html)
и [Fault](https://opendss.epri.com/Fault.html). Отдельно проверяются четыре
опубликованных численных примера Schneider EIG; ссылки и допуски в summary.
Для падения напряжения допускается 0.15 В из-за округления табличных значений,
для примера трансформатора — 0.05 кА. Это сравнение статического эквивалента,
не внешняя валидация траектории двигателя.

Не моделируются трансформаторный бросок тока, насыщение, ударные токи,
нейтраль/земляные КЗ, селективность и вклад двигателей в КЗ. Фиксированное
время отключения должно быть независимо обосновано владельцем. Тепловая
стойкость кабеля от пусков не выводится из статического номинального тока;
динамический I²-аудит двигателя не является расчётом температуры кабеля.
Требуются реальные паспорта, условия применимости таблиц и дополнительные
профили перед заявлением о полном промышленном проектировании.
