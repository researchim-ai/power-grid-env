# Эталонные схемы

Схемы ниже авторские, лицензия Apache-2.0, единицы СИ в каноническом JSON.
Ожидаемый результат не снят с OpenDSS: тесты заново считают его замкнутой формулой,
линейным узловым анализом или определением ZIP.

Каталог `power_grid_env.numerical_suite` перечисляет проверки:

- одна нагрузка и двухузловая линия, постоянная мощность, квадратное уравнение;
- несимметричная постоянная проводимость против независимого MNA;
- Dyn11, запирание нулевой последовательности треугольником, обрыв фазы;
- остров без источника;
- трёхфазное КЗ за сопротивлением Тевенина;
- редукция Крона только при явно твёрдой нейтрали.

Совпадение с симметричным решателем не считается проверкой несимметрии.
IEEE/EPRI-фидеры сюда не копировались: их лицензия проверяется отдельно перед импортом пользователем.
