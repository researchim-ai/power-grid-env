# ADR 0002. Внешний формат

Статус: принято.

Первый внешний формат — скрипт OpenDSS плюс sidecar `pge-import.yaml`. Одновременно не обещаются CIM, CGMES и PSS/E.

`conn=wye` не означает заземление. Без записи в `grounding` импорт отклоняется. `r1/x1` переводятся в диагональную фазную матрицу только если sidecar явно задаёт `impedance_interpretation: diagonal_from_positive_sequence`; взаимная индукция при этом нулевая, и это пишется в отчёт как аппроксимация, а не как измеренный `Z0`.

`switch=yes` становится коммутационным аппаратом. Вид (`breaker`, `disconnector`, …) и ток отключения берутся из sidecar. Импеданс линии-выключателя отбрасывается: аппарат топологический.

Канонический JSON `power-grid-env.network/v1` остаётся внутренним форматом без обязательного закрытого дополнения.
