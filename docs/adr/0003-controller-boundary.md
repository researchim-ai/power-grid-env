# ADR 0003. Граница контроллера

Статус: принято.

Протокол не зависит от библиотеки обучения: `initialize`, `reset`, `act`, `close` по строкам JSON. Первый адаптер — subprocess. Он не является песочницей: отдельный процесс не ограничивает файлы и сеть недоверенного кода. Такую изоляцию нужно строить отдельно до допуска недоверенного исполнителя.

Таймаут фиксирует отсутствие команды и применяет удержание. Это действие политики среды, а не решение алгоритма. Падение процесса и невалидный JSON — отдельные исходы. Скрытая строка сценария и сопротивление КЗ в процесс не передаются.

Блокировки оборудования принадлежат среде всегда. Щит политики сверх блокировок в первой поставке не подменяет блокировку: отклонённая команда остаётся в счётчике попыток.
