# Квазистационарный шаг

Один момент модельного времени обрабатывается так:

1. Исполняются физические команды, срок которых наступил (открытие или включение после `operate_time_s`).
2. Срабатывает накопитель защиты, если выдержка истекла.
3. Считается фазный режим.
4. Публикуются измерения. Они становятся видны контроллеру только в момент `produced + delay`.

Решение контроллера не меняет сеть в то же мгновение, если у аппарата ненулевая задержка. Шаг управления задаётся сценарием и не равен шагу физики.

Разъединитель не отключается под током: предел отключения у него 0. Выключатель имеет положительный `interrupt_current_a`. Маска действия не смотрит на скрытый ток; отказ по току возникает в момент исполнения и остаётся в метриках как попытка нарушения блокировки.

Остров без grid-forming источника не получает искусственный slack. Статус `deenergized_no_source`. Численная несходимость — `numerically_not_converged`; поле `collapse` при этом ложно.

Нагрузка считается обслуженной, только если режим сошёлся и все её фазы не ниже `v_min_pu`. Обесточение — недоотпуск и событие `outage`. Питаемый узел вне полосы — недоотпуск (ниже порога) и отдельно событие `voltage`. Перегрузка сравнивает ток терминала линии с `rating_a`.

Защита QSTS: определённая выдержка и кривые IEC 60255-151:2009, таблица A.1 (SI `k=0.14`, `α=0.02`; VI `k=13.5`, `α=1`; EI `k=80`, `α=2`), формула `t = TMS · k / ((I/Is)^α − 1)`. Сброс линейный за `reset_s` и не является кривой возврата IEC. Distance и differential не реализованы.

Cold-load `1 + (k-1) exp(-t/τ)` включается только при заданных `k` и `τ`. SoC накопителя интегрируется по мощности, вошедшей в сеть, с КПД заряда и разряда; обрезка по кругу кажущейся мощности не создаёт энергию.

Инвертор в режиме исследования КЗ может быть заменён источником тока `fault_current_multiple · Iном`. Это не классическая сверхпереходная машина.
