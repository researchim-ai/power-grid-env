# Ток поля GENROU и динамический ограничитель перевозбуждения

## Реализованный профиль

`coupled_rms` поддерживает явный `overexcitation_limiters` — до восьми
ограничителей по уникальным ID генераторов. Каждый требует GENROU и SEXS.
Пустой список не добавляет состояния или обратную связь OEL. Общие границы
регуляторов теперь действуют для всех coupled-профилей. Модель
`field_current_droop_override` — объявленный инженерный ограничитель с
двумя апериодическими звеньями и ограниченной отрицательной обратной связью
по входу AVR. Это не реализация конкретного типа IEEE OEL и не паспорт
изготовителя. Ограничитель не обрезает ток статора, мощность или поток.

## Физическая величина и базис

Из состояний GENROU восстанавливается знаковая реакция поля `Xad·Ifd`:

```
gd1 = (Xd'' − Xl)/(Xd' − Xl)
gd2 = (Xd' − Xd'')/(Xd' − Xl)²
F = E'q + (Xd − Xd') [gd1·Id + gd2·(E'q − E''d)] + Se·ψ''d
Td'·dE'q/dt = Efd − F
```

`Id = −Im(Igenerator exp(−jδ))`, ток генератора в его собственной
номинальной VA-базе. Насыщение берётся из текущего потока, а не из
напряжения возбуждения. Уравнение согласуется с
[GENROU.XadIfd в ANDES 2.0.0](https://github.com/CURENT/andes/blob/v2.0.0/andes/models/synchronous/genrou.py).

В установившемся режиме `F = Efd`, но при переходном процессе равенства нет.
Поэтому квадрат выхода SEXS не используется как ток ротора.
`rated_field_reaction_pu` явно задаёт реакцию, соответствующую номинальному
току поля; нормированный ток `ifd = |F|/rated_field_reaction_pu`.
Из базиса статора нельзя вывести амперы обмотки возбуждения. В примерах
нормализатор иллюстративный, не измеренный паспортный параметр.

## Уравнения ограничителя

```
dm/dt = (ifd − m)/measurement_time_s
target = clip(feedback_gain_pu·max(m − current_limit_pu, 0), 0, maximum_voltage_bias_pu)
db/dt = (target − b)/bias_time_s
AVR_error = Vref − |Vterminal| + PSS_output − clip(b, 0, maximum_voltage_bias_pu)
```

`measurement_time_s` и `bias_time_s` — секунды;
`feedback_gain_pu` — pu напряжения входа AVR на pu тока поля.
`b` — pu напряжения. Начальное `m` равно фактическому току поля, `b=0`.
Начальный ток должен быть строго ниже уставки; пограничная или уже
перегруженная точка отклоняется, а не подгоняется автоматически.

Положительные постоянные времени и ограниченный target сохраняют
неотрицательность и ограниченность bias. Сохраняются как ограниченный
выход, так и необрезанное состояние; выход внутреннего состояния за
допуск отклоняет результат. Скрытого интегрального накопления здесь нет.
При снятии перегрузки обратная связь плавно исчезает.

Это статическая характеристика с динамическими звеньями, поэтому
установившийся ток может превышать уставку. Особенно это видно при
недостаточном `maximum_voltage_bias_pu`: расчёт показывает фактический
ток и не объявляет жёсткое ограничение выполненным.

## Границы регуляторов и события

Во всех coupled-профилях границы состояний TGOV1 и SEXS имеют непрерывные
root-guards входа и освобождения. На границе состояние удерживается;
фильтры и остальные состояния продолжают эволюцию. Освобождение происходит
при смене знака свободной производной, с отступом лишь порядка машинного
округления от нейтрального нуля. Это устраняет ложный мгновенный цикл
входа/выхода при нулевой производной.

Изменение команды может освободить предел мгновенно. Тогда команда и
освобождение входят в одну пару `pre_event/post_event`. Точные совпадения
попадания разных регуляторов в предел объединяются только на уровне
машинного округления; близкие, но различные события не склеиваются.

Первоначально этот путь включался только при явном OEL. В следующей
[общей секции](INDUSTRIAL_SEQUENCE_RU.md) он перенесён на старые профили
с независимой повторной проверкой; пустой OEL больше не отключает границы.

После электрического отключения генератора статорный ток равен нулю,
но динамика ротора и поля продолжается. SEXS измеряет напряжение со стороны
машины; ограничитель продолжает измерять её поле. Отключение выключателя
не означает отключения возбуждения или турбины.

## Воспроизведение

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
python -m power_grid_env.cli run-study cases/studies/generator_excitation_voltage_step.json --out /tmp/excitation-step
python -m pytest tests/test_generator_excitation.py
python -u -m benchmarks.generator_excitation_validation --out reports/excitation-new --batch-size 2 --native-batch-size 1
# Повторять с тем же каталогом до status=complete, passed=true.
```

Паспорт задаётся в `coupled.overexcitation_limiters`:

```json
{
  "generator_id": "g2",
  "model": "field_current_droop_override",
  "rated_field_reaction_pu": 1.0,
  "current_limit_pu": 1.4,
  "measurement_time_s": 0.04,
  "feedback_gain_pu": 0.3,
  "bias_time_s": 0.08,
  "maximum_voltage_bias_pu": 0.15
}
```

Каналы `g2.OEL.*`: `field_reaction_pu`, `field_current_pu`,
`measured_current_pu`, `bias_pu`, `bias_state_pu`, `current_limit_pu`.

## Независимая проверка

Полный контур решается также SI-MNA-моделью с физическими токами обмоток,
отдельными передаточными блоками и другим интегратором (DOP853 вместо Radau).
Она не импортирует производственные функции восстановления поля,
производных ограничителя или определения границ регуляторов.

Корпус: удержание, рост задания, восстановление, недостаточная управляющая
способность, насыщение GENROU, два ограничителя, прямой пуск двигателей,
ручное открытие генератора, тепловое отключение, верхний и нижний пределы SEXS.
Проверяются полные траектории, последовательности и время событий,
непрерывность состояний, баланс токов и собственные базы машин.

Отдельный корпус ANDES 2.0.0 проверяет только физическую величину `XadIfd`
на опытах без OEL: удержание, рост задания, насыщение, каждый на трёх шагах.
Новый канал берётся непосредственно из алгебраической переменной ANDES.
Эти запуски не подтверждают native-OEL и не подменяют SI-проверку замкнутого
контура. Неподдерживаемый OEL native-адаптер отклоняет до запуска рабочего
процесса; малосигнальный анализ с OEL пока также отклоняется явно.

Протокол фиксирует исходники, входы и допуски перед расчётом. Изменение
решателя или эталона требует нового корпуса. Частичные или не прошедшие
сравнение результаты не являются подтверждением реализации.

## Следующие физические расширения

Тепловая реплика ротора, нулевое приложенное напряжение поля и общие
границы регуляторов реализованы в [следующей секции](INDUSTRIAL_SEQUENCE_RU.md).
Конкретный [UEL MNLEX2](MNLEX2_VALIDATION_RU.md) имеет native-проверку
компонента и отдельную SI-проверку сетевого контура. Остаются конкретные
стандартные/OEM OEL, разрядная цепь поля и штатный native-эталон замкнутого
ограничителя. Температура и натурная квалификация
этим разделом не заявляются.
