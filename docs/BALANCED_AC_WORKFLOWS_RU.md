# B10.2: единый сбалансированный AC-профиль

Одна схема `power-grid-env.balanced-ac/v1` используется для Newton power flow,
локального AC OPF, AC WLS и статического N−1. Сохраняются ID узлов, порядок
генераторов, индексы ветвей, паспортные ограничения и единицы. Неявного переноса
несимметричной `Network` в этот профиль нет. Импорт MATPOWER читает числовые
матрицы как данные и никогда не исполняет MATLAB.

## Готовые исследования

Из корня исходников после установки пакета:

```sh
python -m power_grid_env.cli steady-study run --study cases/studies/balanced_ac_power_flow.json --out /tmp/ac-pf
python -m power_grid_env.cli steady-study run --study cases/studies/balanced_ac_state_estimation.json --out /tmp/ac-estimation
python -m power_grid_env.cli steady-study run --study cases/studies/balanced_ac_opf.json --out /tmp/ac-opf
python -m power_grid_env.cli steady-study derive /tmp/ac-opf --task n1 --out /tmp/derived-n1.json
python -m power_grid_env.cli steady-study run --study /tmp/derived-n1.json --out /tmp/n1-part --max-cases 1
python -m power_grid_env.cli steady-study run --study /tmp/derived-n1.json --out /tmp/n1-resumed --resume-from /tmp/n1-part
python -m power_grid_env.cli steady-study verify /tmp/n1-resumed
python -m power_grid_env.cli steady-study export /tmp/n1-resumed --out /tmp/n1-results.zip
```

Каждый выходной каталог и выходной файл должны быть новыми. Приостановленная
попытка возвращает код 2 и `status=paused`; продолжение создаёт новый каталог,
исходная попытка остаётся неизменной. `--cancel-file` проверяется перед расчётом,
а в N−1 дополнительно между вариантами. `--time-budget` действует только в N−1
и проверяется между вариантами: это не жёсткий таймаут внутри решателя.

Для собственного MATPOWER-файла:

```sh
python -m power_grid_env.cli steady-study import-matpower --source model.m --out /tmp/case.json
```

Полученный `case.json` помещают в поле `case` документа исследования. Определение
можно менять обычным JSON-редактором, без редактирования Python-модулей. Четыре
закреплённых примера лежат в `cases/studies/balanced_ac_*.json`. Авторский пример
имеет отрицательный Pd на одном узле: это явно заданная результирующая активная
инъекция. Он построен по точным комплексным напряжениям, не по натурной записи.

## Единицы и перенос

- Базис: MVA; генерация, нагрузки и измерения мощности: MW/Mvar.
- R/X, шунты G/B и напряжения: pu. В MATPOWER Gs/Bs переводятся с базиса MVA.
- `rate_a`: MVA каждого конца ветви; **0** означает отсутствие ограничения.
  Большое конечное значение не превращается в «без ограничений».
- Угол в модели и результатах режима — градусы; угловой измеритель `va_rad`
  и координаты ковариации — радианы относительно опоры.
- Нулевой `ratio` MATPOWER означает единичный tap; учитываются фазовый сдвиг,
  зарядные проводимости и оба конца трансформаторной ветви.
- Генераторный Vg переносится как уставка управляемого узла. Несогласованные
  уставки нескольких генераторов на одном узле отклоняются.
- Выведенные генераторы не исполняются; отключённые ветви сохраняют индексы.
  Поддержаны буквальные polynomial gencost; piecewise, Q-objective и неизвестные
  поля нового JSON-профиля отклоняются, а не приближённо угадываются.
  Неизвестные MATPOWER-устройства (например dcline), повторные/индексные
  присваивания и вычисляемый baseMVA также отклоняются. Метаданные areas,
  bus_name, gentype, genfuel не превращаются в дополнительное оборудование.

`derive` принимает только проверенный OPF-артефакт и повторно проверяет баланс,
ограничения генераторов, напряжения, углы и мощности обоих концов ветвей. Флаг
успеха оптимизатора сам по себе недостаточен. В производном документе сохраняется
ссылка по хешам на исходный результат. Глобальная оптимальность не заявляется.

## Расчёт режимов и N−1

Newton использует аналитический якобиан и поиск длины шага. Активные мощности
неопорных генераторов фиксированы; slack покрывает баланс. Для PV-узлов действует
явное монотонное переключение PV→PQ при суммарном пределе Q; политика отключается
через `enforce_q_limits=false`. Выход slack за паспортные пределы отмечается
как нарушение; напряжение не подстраивается скрытой оптимизацией.

N−1 отключает по одной выбранной активной ветви, без перенумерации остальных.
`branch_indices` позволяет задать точный набор. Каждый вариант сохраняется в
`cases.jsonl`, включая отказ Newton и острова. Остров не называется коллапсом;
PV-генератор не становится опорой автоматически. Отдельно выдаются:
`completed` — оценены все варианты; `converged` — численная сходимость режима;
`within_limits` — ограничения режима выполнены; `secure` — базовый режим и все
оценённые аварийные варианты допустимы. Несходимость не доказывает физическую
невозможность режима. Автоматического redispatch и сброса нагрузки нет.

Checkpoint содержит номер последнего записанного варианта, длину и SHA-256
журнала, хеш определения и производителя. Записи и checkpoint синхронизируются
с диском. Продолжение разрешено из запечатанной паузы/отмены/исчерпания бюджета;
незапечатанная попытка после аварийного завершения требует отдельного разбора.
Хеши подтверждают целостность, но не авторство. Пределы артефактов совпадают с
B09; переполнение не становится успешным полным исследованием.

## AC-оценивание состояния

Поддержаны |V|, угол, P/Q инъекции и P/Q обоих концов ветвей. `sigma` — стандартное
отклонение в единицах соответствующего измерителя, не дисперсия. Предполагаются
независимые ошибки; коррелированные ошибки и ошибки топологии не идентифицируются.

Аналитические производные проверяются центральными разностями всех измерителей,
включая tap, фазовый сдвиг и зарядные проводимости. Наблюдаемость определяется
SVD взвешенного якобиана, без возведения обусловленности в квадрат через Gram.
В отчёте есть ранг, обусловленность, полная локальная ковариация и её координаты.
Для численного поиска WLS задана область 0.05 < |V| < 2 pu и ±2π для
неопорных углов; старт вне неё отклоняется явно.
Нормированные остатки учитывают leverage. Для критических измерителей с нулевой
остаточной дисперсией выдаётся `null`, а не ложный нулевой остаток. При отсутствии
избыточности χ²-проверка недоступна; это не «чистые данные».

`reject_bad_data=true` удаляет максимум по одному измерителю за итерацию при
провале χ² и превышении заданного порога. Проверяется сохранение наблюдаемости,
сохраняются история и бюджет удалений. Численное завершение (`completed`) и
прохождение проверки данных (`accepted`) различаются. Локальный минимум WLS
не считается доказанным глобальным решением.

## Независимая локальная сверка

```sh
python -m pytest tests/test_balanced_ac_workflows.py tests/test_ac_estimation.py
python -m benchmarks.balanced_ac_acceptance --out /tmp/ac-native-acceptance
python -m benchmarks.steady_cli_acceptance --python /absolute/venv/bin/python --source . --out /tmp/ac-installed-acceptance
```

Первая команда не требует внешнего кэша: точные авторские фазоры и отдельное
суммирование терминальных токов, плюс прямой OpenDSS для обычной трёхузловой сети.
Вторая требует уже имеющиеся PGLib 3/5/14/118 и ANDES **2.0.0**. Она ничего не
скачивает. ANDES самостоятельно разбирает исходные MATPOWER-файлы; используются
его собственные терминальные RHS-мощности. Сверяются PF 5/14/118, измерения и
ошибочный измеритель, девять заранее выбранных отключений, OPF-dispatch 3/5/14,
а также полный N−1 118 с побайтным сравнением после продолжения.

В независимом профиле Q-переключение выключено с обеих сторон. Встроенные ANDES
`r+1e-8`, `x+1e-8` сохраняются и объясняют ненулевое расхождение; допуски до оценки:
1e-6 pu для |V|, 1e-6 rad для угла, 1e-5 pu для мощности, 1e-6 pu для AC WLS.
Встроенная pq2z-конверсия ANDES также отключена. Q-limit switching отдельно
проверяется авторскими предельными случаями; девять независимых отключений
не выдаются за независимую сверку каждой ветви большого корпуса.

Третья команда выполняет сквозные процессы установленного wheel из пустого
каталога, включая derive, PF, OPF, AC WLS, паузу и продолжение N−1, отмену,
перенос, отказы повторной записи и подмену артефакта. Она не требует ANDES.

Матрица профиля ограничена: плотная AC-схема до 512 узлов в API, AC WLS до 128
узлов/5000 измерителей. Численная сверка закреплена до 118 узлов. Это не обещание
произвольного масштаба, не несимметричный OPF/SE и не натурная квалификация.
