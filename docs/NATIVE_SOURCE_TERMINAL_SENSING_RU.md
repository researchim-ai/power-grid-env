# Истинное напряжение источника для нативных контакторов

Дата: 1 ноября 2026. Восстановление клеммных измерений проверено на всех
48 сохранённых нативных траекториях 16 случаев. Новых интегрирований ANDES
на этом этапе нет. Сохранённые траектории и их происхождение проверяются
по предыдущему `delivery.json`; производственный пакет не меняется.

В нативном эквиваленте сопротивления источника и линии объединены.
Slack задаёт внутреннюю ЭДС. Между ней и исходными клеммами источника
остаётся падение на его сопротивлении, которое зависит от тока двигателей
и генератора. Подставлять Slack-напряжение в source-sensing контактор нельзя.

## Восстановление из нативных портов

`benchmarks/native_terminal_measurements.py` использует нативные P/Q всех
моторов, P/Q генератора, напряжение общей моторной шины, заданную ЭДС и
раздельные сопротивления источника/линии. Каналы производственного решателя
в наблюдатель не передаются.

Для положительной последовательности без зарядных проводимостей:

- S — суммарная трёхфазная мощность моторов за вычетом генерации;
- V — фазное RMS-напряжение принимающей шины;
- I = conj(S)/(3·|V|) в системе координат принимающего напряжения;
- E = V + (Zист + Zлинии)·I;
- Vклемм = V + Zлинии·I;
- Sклемм = 3·Vклемм·conj(I).

Поворот системы координат меняет только фазу. Масштаб не подгоняется;
невязка относительно заданной ЭДС должна быть не больше 1e-6 о.е.
При нулевом принимающем напряжении ток определяется уравнением ветви,
если суммарное сопротивление ненулевое. Неоднозначный нулевой случай
отклоняется, нулевой ток не подставляется автоматически.

## Полученные доказательства

На тонком шаге 62,5 мкс максимальная ошибка измеряемого напряжения —
около 2,59e-6 о.е. при допуске 1e-4; ошибка мощности источника — около
155 Вт/вар при допуске 1000. Для каждого из 16 случаев проверено уменьшение
максимальной нормированной ошибки от 250 к 62,5 мкс. Наибольшая невязка
восстановления заданной ЭДС — около 2,61e-8 о.е.

Ошибочная подстановка внутренней ЭДС вместо клемм дала расхождение до
0,0357 о.е. Это отдельный отрицательный контроль измерительного интерфейса.
Проверены оба направления потока мощности, питание генератором, отсутствие
ЭДС, стороны внешнего скачка, нулевое принимающее напряжение, повреждение
портовых данных, идентичность задания и независимость от основной модели.

Грубые шаги не скрыты: в семи траекториях ошибка P/Q источника на 250 мкс
превышает 1000, достигая примерно 2485 Вт. На тонком шаге все случаи проходят.
Изначально черновой агрегатор ошибочно требовал допуск тонкого шага на всех
шагах; этот отказ сохранён отдельно. Применён протокол исходной нативной
сверки: записать все ошибки, проверить сходимость и допуски на тонком шаге.
Ни пределы ошибок, ни формула измерения для этого не менялись.

## Воспроизведение и оставшиеся ворота

```bash
python3 -m benchmarks.native_sensing_validation \
  --out /tmp/native-terminal-sensing
python3 -m pytest tests/test_native_terminal_measurements.py
```

Отчёт: `reports/native-terminal-sensing-2026-11-01/`.
Нативные данные остаются входами наблюдателя; переключения в них пока
получены из независимого SI-контроллера. Восстановленное напряжение ещё
не замыкает самостоятельный нативный контроллер. Его непрерывные пороги,
выдержки, тепловые корни, совместные переключения и бюджет переходов
нужно квалифицировать отдельно. Натурная точность и промышленная
готовность этим наблюдателем не подтверждаются.
