# power-grid-env / web

Локальный двуязычный сайт проекта: изометрическая электросеть, переключаемый
AI-слой, интерактивные иллюстрации пуска/провала/острова, графики, экспорт JSON
и документация с копированием команд. Адаптивная вёрстка, клавиатурная навигация,
режим уменьшенного движения, локальные шрифты. Внешних CDN, API и аналитики нет.

## Запуск

Из корня проекта:

```sh
cd web
npm run dev
```

Открыть `http://localhost:5173`. Node.js 20+, установка зависимостей не нужна.
Другой порт: `npm run dev -- --port 8080`. Сервер слушает только loopback.
Это локальный preview-сервер, не production backend.

`index.html` можно открыть непосредственно; HTTP рекомендуется для штатной
работы буфера обмена и обновляемого JSON-снимка метрик.

## Проверка и сборка

```sh
npm run check
npm run build
```

Сборка создаёт статический `dist/`, который можно разместить на статическом
хостинге. Она обновляет локальную копию статуса и число обязательных тестов из
`../plans/CURRENT_STATUS.md`. Числа четырёх профилей/12 трасс и дата относятся
к опубликованному на сайте снимку B15 от 06.11.2026; при смене этого корпуса
обновите также подписи в `index.html` и переводах `app.js`.

## Структура

- `index.html` — страница, изометрические SVG-объекты и диалог документации.
- `styles.css` — дизайн, адаптивность, печать и reduced-motion.
- `app.js` — RU/EN, выбор узлов, графики и демонстрационные сценарии.
- `assets/` — локальные шрифты, лицензии, иконка и снимок статуса.
- `scripts/` — сборка и проверка без сторонних зависимостей.

## Что выполняет демонстрация

Графики в браузере — **иллюстративные**, их формулы находятся в `makeData()`.
Они не запускают Python, не являются эталонными траекториями и не предназначены
для инженерного вывода. Экспорт JSON содержит `illustration_only: true` и
`physical_solver_used: false`. Настоящие команды проекта доступны в документации
на сайте; выполнение ядра остаётся локальным и отдельным.

## Лицензии

Код сайта — Apache 2.0, как и проект. Локальные шрифты Lato распространяются
по OFL-1.1; исходные условия и атрибуция сохранены в `assets/FONT-LICENSE.txt`.
Шрифты сокращены до используемых диапазонов Unicode, формат WOFF, и переименованы
в Grid Sans с сохранением исходной атрибуции (`assets/FONT-NOTICE.txt`).
