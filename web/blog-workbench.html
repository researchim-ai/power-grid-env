Как собрать сеть и выполнить расчёт

Конструктор, расчёты, визуализатор и среда агента находятся в отдельном приложении Power Grid Studio. Сайт с блогом можно размещать независимо от него.

Как запустить Power Grid Studio

Сайт рассказывает о проекте, а Studio используется для работы со схемами, расчётами и агентами. Для запуска приложения из корня репозитория выполните команды:

python -m pip install -e .
PGE_PYTHON=python npm --prefix studio run dev

Откройте http://localhost:5174. Нужны Node.js 20+ и Python с установленными зависимостями проекта. Studio запускается независимо: сайт не требуется ни для расчётов, ни для работы агента.

Если приложение размещено по отдельному адресу, его можно указать в настройках сайта. Ссылки будут открывать Studio; проекты и расчётный API при этом останутся в самом приложении.

Подготовьте схему в конструкторе

Начните с конструктора: добавьте шины, линии и нагрузки, задайте параметры оборудования. Сначала выберите профиль исследования — от него зависит, какие элементы можно использовать и какой расчёт будет выполнен.

Проверьте единицы измерения и номинальные напряжения. Сохраните исходный проект, прежде чем менять оборудование: так будет проще сравнить варианты и вернуться к начальным данным.

Проверьте модель и запустите расчёт

Проверка схемы помогает найти ошибки, которые мешают собрать расчётную модель. После неё запустите выбранное исследование и посмотрите, выполняются ли ограничения по напряжению, токам и загрузке.

Новые расчёты выполняет локальное Python-ядро через сервер проекта. Статическую сборку сайта можно использовать для просмотра страниц и сохранённых результатов; для собственных расчётов нужен запущенный локальный сервер.

Изучите результаты в Grid Studio

В Grid Studio можно посмотреть однолинейную схему, выбрать оборудование и изучить его измерения. Сохранённые RMS-расчёты позволяют проследить события и изменения величин во времени. Анимация потоков помогает читать схему, но не выполняет новый расчёт.

Обратите внимание на источник данных. На главной странице показаны иллюстративные графики, а в Grid Studio — записи расчётов. Это разные представления, и использовать их для инженерных выводов следует с учётом указанного профиля.

Попробуйте задание в Agent Lab

В Agent Lab доступны открытые учебные задания. Вы можете вызывать инструменты, читать измерения и смотреть историю действий. После изменения схемы нужен повторный расчёт. Проверочные и тестовые задания через этот API не выдаются.

Agent Lab показывает, как устроена среда агента. Обученная Qwen пока не подключена к этому интерфейсу: результаты статьи об обучении получены в отдельных локальных GPU-прогонах с собственным набором наблюдений и инструментов.
