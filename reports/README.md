# Локальные результаты запусков

Этот каталог предназначен для трасс симуляции, отчётов pytest, результатов
бенчмарков, wheel/venv-проверок, внешних измерений и снимков исходников,
сохранённых вместе с доказательствами. Новые результаты исключены из Git.
Они остаются на диске; для обмена используйте артефакты CI или отдельный архив.

Исходники проверок находятся в `benchmarks/`, воспроизводимые задания —
в `cases/`, документация — в `docs/`, ограничения зависимостей — в `requirements/`.
Ссылки из документации на датированные отчёты указывают на локальные артефакты:
после нового клонирования их потребуется получить отдельно или пересчитать.
Отсутствие отчёта не означает успешную квалификацию.

Ранее отслеживаемые отчёты сохранены для совместимости с историей проекта.
Правила `.gitignore` не прекращают отслеживание уже версионируемых файлов.

Скрипты в датированных `sources/` — снимки конкретного запуска, включая
локальные проверяющие скрипты. Если такой скрипт нужен как постоянный инструмент,
его следует отдельно оформить в `benchmarks/`; весь снимок отчёта добавлять
в репозиторий для этого не требуется. Lock-файлы зависимостей коммитить нужно,
wheel-файлы и установленные окружения — нет.
